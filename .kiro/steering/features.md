# Високорівневий список фіч

Довідковий документ із переліком усіх функціональних можливостей системи, згрупованих за модулями та ролями.

## Публічні сторінки (без автентифікації)

- Головна сторінка
- Ліцензія / умови використання
- Політика конфіденційності

## Автентифікація

- Вхід через Google OAuth
- Автоматичне створення облікового запису при першому вході
- Вихід із системи

## Онбординг нового користувача (Player Claim)

- Пошук існуючого гравця за ПІБ (з фільтрацією за країною та містом)
- Заявка на привʼязку до існуючого гравця
- Заявка на створення нового гравця (з вибором країни зі списку та міста каскадом країна → місто; країна — лише з довідника, місто можна ввести вручну)
- Очікування модерації заявки

## Основні сторінки (ROLE_PLAYER)

### Турніри

- Список опублікованих турнірів із пагінацією та фільтрацією за сезоном
- Картка турніру: загальна інформація, формат, дедлайни, офіційні особи
- Результати турніру: загальна таблиця результатів усіх команд
- Детальні результати: розбивка по турах і запитаннях
- Сесії турніру: перелік ігрових сесій із місцем проведення, датою та посиланням на анонс гри (за наявності)
- Картка сесії: склади команд, відповіді, спірки, посилання на анонс гри (за наявності)

### Команди

- Список команд із пагінацією та пошуком (фільтрація за країною та містом, каскадом країна → місто)
- Картка команди: поточний склад, місто (з країною для неукраїнських команд), капітан
- Історія переходів гравців у команді
- Можливість подати заявку на капітанство

### Гравці

- Список гравців із пагінацією та пошуком (фільтрація за країною та містом, каскадом країна → місто)
- Профіль гравця: ПІБ, місто та країна, контакти (для модераторів та власника)
- Турнірна історія гравця
- Статистика по сезонах

### Майданчики

- Список затверджених майданчиків із пошуком (фільтрація за країною та містом, каскадом країна → місто)
- Картка майданчика: назва, місто та країна, опис (з клікабельними посиланнями) та посилання, список турнірів, що проводилися (з посиланням на анонс гри для кожного відіграшу, за наявності)

## Особистий кабінет (My)

### Контакти

- Перегляд і оновлення контактної інформації (Telegram, Facebook, телефон)

### Майданчики

- Список майданчиків, якими гравець може керувати: створені ним плюс ті, де він представник (без дублів)
- Створення нового майданчика (з опційними описом та посиланням)
- Керувати майданчиком (перегляд у списку, редагування, оновлення) може як його творець, так і будь-який представник — з однаковими правами
- Редагування майданчика: опис і посилання доступні для редагування будь-коли (і до, і після схвалення); список представників можна редагувати лише після схвалення майданчика

### Управління командою (капітан)

- Перегляд поточного складу
- Додавання гравців до команди
- Виключення гравців зі складу
- Вихід із команди
- Редагування інформації про команду

### Турніри (організатор)

- Список власних турнірів
- Створення турніру (чернетка)
- Редагування турніру
- Видалення чернетки
- Публікація турніру (подання на модерацію)
- Завантаження / видалення пакета запитань турніру (доступний лише ведучим схвалених відіграшів)
- Призначення офіційних осіб (редактор, організатор, ігрове журі, апеляційне журі)

### Заявки на проведення сесій (представник)

- Список заявок на проведення по всіх майданчиках, представником яких є гравець (заявки спільні для всіх представників майданчика, а не лише того, хто подав; з посиланням на анонс гри, за наявності)
- Створення заявки на конкретну сесію (з обовʼязковим призначенням ведучого — гравця з акаунтом; з опційним посиланням на анонс гри)
- Редагування / видалення заявки будь-яким представником майданчика (посилання на анонс гри редагується поки відкрита реєстрація)
- Подання заявки на модерацію

### Відіграші ведучого (ведучий)

- Список власних відіграшів, де гравець призначений ведучим (лише схвалені)
- Сторінка конкретного відіграшу з доступом до пакета запитань турніру

### Подання результатів сесії (представник)

- Внесення складів команд на сесії
- Внесення відповідей команд по запитаннях
- Подання результатів
- Доступ до внесення результатів має будь-який представник майданчика сесії, а не лише той, хто подав заявку

### Управління заявками на сесії (організатор)

- Перегляд заявок на проведення сесій свого турніру (окремі секції: на розгляді, схвалені, відхилені; з посиланням на анонс гри, за наявності)
- Затвердження / відхилення / відкликання заявок
- Повторне затвердження раніше відхиленої заявки (відхилені заявки не зникають, а зберігаються з причиною відмови)

### Спірки (Disputes)

- Подання спірки на відповідь
- Перегляд поданих спірок
- Видалення спірки (до подання)

### Апеляції (Appeals)

- Подання апеляції (на зарахування або зняття відповіді)
- Перегляд апеляцій свого турніру

### Розгляд спірок (ігрове журі)

- Список турнірів зі спірками для розгляду
- Прийняття / відхилення спірки з коментарем

### Розгляд апеляцій (апеляційне журі)

- Список турнірів з апеляціями для розгляду
- Прийняття / відхилення апеляції з вердиктом

## Модерація

### Заявки гравців

- Список заявок на привʼязку до гравця (з відображенням країни та міста)
- Затвердження / відхилення заявки (для нового гравця модератор може скоригувати місто в межах країни заявки)

### Заявки на капітанство

- Список заявок на капітанство
- Затвердження / відхилення з коментарем модератора

### Майданчики

- Список незатверджених майданчиків (з описом та посиланням заявки для перегляду)
- Затвердження / відхилення майданчика

### Модерація турнірів

- Список турнірів на модерації
- Затвердження / відхилення публікації турніру з коментарем

### Управління користувачами

- Блокування користувача з вказанням причини
- Розблокування користувача

## API (AJAX-ендпоінти)

- Автокомплект країн
- Автокомплект міст
- Автокомплект гравців
- Автокомплект команд
- Отримання гравців команди на сесії

## Ролі та доступ

Ієрархія: `ROLE_ADMIN` → `ROLE_MODERATOR` → `ROLE_PLAYER` → `ROLE_USER`

| Роль | Доступ |
|------|--------|
| Анонім | Головна, ліцензія, політика конфіденційності, OAuth-ендпоінти |
| ROLE_USER | Player Claim (заявка на привʼязку до гравця), автокомплект гравців/міст |
| ROLE_PLAYER | Усі основні сторінки (турніри, команди, гравці, майданчики), особистий кабінет |
| ROLE_MODERATOR | Панель модерації (заявки, майданчики, турніри, користувачі) |
| ROLE_ADMIN | Повний доступ до системи |

Додаткові ролі (не в ієрархії Symfony, визначаються зв'язками):

| Роль | Опис |
|------|------|
| Капітан | Управляє складом команди (визначається через TeamPlayer.isCaptain) |
| Організатор | Створює та управляє турнірами (визначається через TournamentOfficial) |
| Представник | Подає заявку на проведення відіграшу, вносить результати (визначається через VenueRepresentative — належність гравця до майданчика сесії; заявка спільна для всіх представників майданчика). Поле TournamentSession.representative фіксує лише того, хто подав заявку |
| Ведучий | Веде відіграш; має доступ до пакета запитань схваленого відіграшу (визначається через TournamentSession.host) |
| Ігрове журі | Розглядає спірки (визначається через TournamentOfficial.role = game_jury) |
| Апеляційне журі | Розглядає апеляції (визначається через TournamentOfficial.role = appeal_jury) |

## Ключові бізнес-процеси

### Життєвий цикл турніру

```
Чернетка → Подання на модерацію → Очікує модерації → Затверджено/Відхилено → Опубліковано
```

### Життєвий цикл заявки на сесію

```
Створено → Подано → Очікує → Затверджено / Відхилено / Відкликано
                              Відхилено → Затверджено (організатор передумав)
                              Відхилено → Очікує (представник подав повторно)
```

### Процес спірки

```
Створено → Подано → Прийнято / Відхилено (ігрове журі)
```

### Процес апеляції

```
Очікує → Прийнято / Відхилено (апеляційне журі)
Типи: зарахування відповіді / зняття запитання
```

### Процес заявки на капітанство

```
Очікує → Затверджено / Відхилено (модератор)
```

### Процес привʼязки гравця

```
Подано → Затверджено / Відхилено (модератор)
```

## Формати турнірів

- **Централізований** — одна сесія в одному місці
- **Розподілений** — кілька сесій на різних майданчиках

## Режими проведення

- **Офлайн** — очна гра
- **Онлайн** — дистанційна гра
- **Змішаний** — комбінований формат
